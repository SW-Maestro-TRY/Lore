# 동작 key → 16프레임 후처리 프로파일. service_motion_post.py 의 --profile 에 그대로 실린다.
#
# ★ 왜 동작마다 다른가
#   16프레임은 한 칸이 독립이 아니라 **한 동작이 이어지는 하나의 루프**다. 그래서 "무엇을
#   기준으로 칸을 맞출 것인가" 가 동작의 성질에 따라 달라진다.
#     서 있는 동작   발이 실제로 고정이라 발을 기준으로 맞춘다
#     구르는 동작    공중에 뜨는 칸이 있어 발 기준이 흔들리지만, 확정본은 발 정렬로 나왔다
#     넘어지는 동작  뒤로 눕는 칸에서 발이 화면 밖으로 나가 발 기준이 통째로 오판된다.
#                    그래서 엉덩이·등이 바닥에 닿는 자리(접지앵커)를 기준으로 맞춘다
#   칸 번호·기준을 코드에 박지 않는다는 원칙의 16프레임 판이다 — 코드가 아니라 이 표를 고친다.
#
# ★ 여기 없는 동작은 굽지 못한다 — 조용히 아무 프로파일로 떨어지지 않는다.
#   기본값을 두면 새 동작을 확정하고 이 줄을 깜빡했을 때, 검수를 거치지 않은 후처리로 구워진 그림이
#   사용자에게 그대로 나간다. 그건 화면을 봐야만 드러나므로 **없으면 멈춘다.**
#   멈출 때는 이 파일 이름과 빠진 key 를 그대로 말한다.
#
# ★ 형식: <동작 key> = script=<모듈>, <옵션>=<값>, ...
#   script 는 이 폴더의 파이썬 모듈 이름(확장자 없이). 나머지는 그 모듈 main() 의 인자다.
#   이름이 틀리면 service_motion_post.py 가 가능한 값을 대며 멈춘다.

# 구르기 — 검수를 마친 확정 조건. 확정본 v02 를 만든 그 조합이다.
#   state16_v2 + 발 정렬. v2 자체 기본값은 align=none 이지만 확정본은 foot 으로 나왔다.
roll = script=state16_v2, align=foot

# 뒤로넘어짐 — 검수를 마친 확정 조건(v6b). 확정본 v6b 를 만든 그 조합이다.
#   격자를 다시 굽지 않고 후처리 앵커만 바꿔서 만든 판이다.
#   접지앵커(엉덩이·등이 닿는 자리)로 맞추고, 누운 구간은 같은 x 에 고정한다(seat-lock=global).
#   실측: 누운 구간 f09~f16 접지앵커 흔들림 최대 15.0px → 1.0px ·
#         앉음→누움 경계 최대 21.0px → 0.5px
fall_back = script=state16_v3, cut=marks, align=seat, seat-lock=global
