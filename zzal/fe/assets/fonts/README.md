# 짤 로컬 글꼴

Gaegu400/700·Gowun Dodum400의 Google Fonts 원본 subset을 합친 기존 검증 파일이다. 이번 변경에서 파일 내용을 수정/재-subset/새 glyph 생성하지 않았다. 기존 literal font-family와 CSS 변수 모두 같은 세 원본을 사용한다.

- 원천 프로젝트: https://fonts.google.com/specimen/Gaegu · https://fonts.google.com/specimen/Gowun+Dodum
- Gowun 원작자: https://github.com/yangheeryu/Gowun-Dodum
- 내장 name ID0의 copyright와 name ID14의 SIL OFL 링크를 유지한다: https://openfontlicense.org/
- OFL.txt는 SIL OFL1.1 일반 본문과 두 글꼴의 내장 copyright를 포함한다. 원래 Gaegu에 없는 음절은 기존 Gowun fallback이 담당하며, 일본어 폰트를 추가하지 않는다.
