# 지금 되는 것과 앞으로 할 것

소개서에 숫자나 기능을 쓸 때 이 표를 기준으로 합니다. 2026-09-27 기준.

## 먼저 알아 둘 것 — 운영과 develop 이 다르다

2026-09-27에 `https://lorecomic.com/webtoon`(운영, main)을 열어 보니 develop 과
문구부터 다릅니다. 운영은 "오늘 무료 3편", "한 편 그리는 데 보통 10분 정도",
타겟 세 줄(웹소설·팬픽 작가 / 창작 입문자 / 기획자)이 나옵니다. develop 의 랜딩
(`webtoon/fe/screens/landing/Landing.tsx`)은 "보통 5~15분", "지금은 모든 기능이
무료"입니다. 운영 DB 의 웹툰 작업은 같은 날 기준 1건뿐이었습니다.

아래 표는 **develop 코드 + 로컬 실제 생성 기록** 기준입니다. 대외 자료에 쓸 때는
그 기능이 운영에 올라갔는지 따로 확인합니다.

## 실측 숫자

로컬 DB(`webtoon_job`, `webtoon_character`)와 `webtoon/ai/work/runs/*/meta.json`
에서 뽑았습니다. 모두 실제 API 를 부른 생성이고, 한 번에 한 편만 돌려 대기 줄이
없던 조건입니다.

| 항목 | 실측 | 표본 | 비고 |
| --- | --- | --- | --- |
| 캐릭터 1개 | 약 41~47초 (중앙값 약 45초) | 7건, 9-23~9-26 | 사진·글 입력 차이 거의 없음. 화면 문구는 "약 30초" |
| 웹툰 1화 · 파도 · 빠르게 결과부터 | 약 3분 (2.8~3.1분이 대부분) | 10건, 9-13~9-19 | 기존 소개서·코드 설명은 "약 8분" |
| 웹툰 1화 · 파도 · 2번 확인하며 | 약 4~6분 | 6건 | 사람이 시트·이야기를 고르는 시간 포함 |
| 한 편 분량 | 6장 (가끔 5장) | 위 run 들의 `PAGE_IMAGE` 수 | 표지 포함 |
| 한 편 원가 · 파도 | 약 1,000~1,200원 | 같은 run 들의 `total_krw` 합 | 대외 자료에는 쓰지 않음 |
| 물결 · 너울 | 실측 없음 | 0건 | 코드 설명은 약 6분 / 약 15분 |

나중에 다시 잴 때: 표본이 로컬 한 대, 파도만 있습니다. 운영에서 대기 줄이 생기면
`started_at - created_at` 만큼 더 걸립니다.
