## 아직 안 된 것 (피드백 받았으나 미해결)

- 캐릭터가 의도대로 안 나옴(학년·외모 미반영) — 원인 미확인
- 그림 안에 그려지는 한글 깨짐 — 원인 찾는 중(OpenAI 직접 전환 뒤 재측정)
- 생성 속도, 컷 단위로 만들기 — 달라지지 않음
- AI가 쓴 글의 꾸밈 표현(「이렇게 하는 게 좋을 것 같음」) 필터 — 없음
- 「웹툰보다 만화 같다」(한 장에 컷을 몰아 넣는 배치) — 과금 실험 필요
- 방화벽(WAF)이 막을 때 안내 없음 — 「요청이 실패했습니다 (403)」만

## 만드는 중·방향 (문서·실험 단계)

- 세계관 체험: 등장인물·관계·사건이 설계된 세계에 내 캐릭터를 끼워 넣는 경험. 지금 장르 설정집은 무대만 있음.
  입력 검증(막지 않고 물어봄), 공간 칸, 캐릭터 구별률 지표. 명세는 [experience.md](experience.md)
- 설정 보존·활용 재측정: 전독시 1화, 로어북 vs 텍본, 보존 62.5% 대 67.4%(차이 확정 불가),
  활용 8/12 대 5/12, 입력 89% 감소, 진명 규칙 추출 구멍 발견(`haeun/설정보존-2026-11-02`)
- 결제 켜기(페이앱 심사 → 보증보험 → 결제), 가격안(20C·₩5,900 / 장면 한 장 5C ₩1,900 보류)
- 월 멤버십, 광고 보상·오퍼월(1C 원가 약 157원이 광고 단가보다 커서 보류)
- 캐릭터 키우기와 잇기(짤 → 웹툰 자동 연결 없음, 상훈 영역)
- 여러 화에 걸친 긴 이야기를 회차로 나눠 연재하기(지금은 1화씩, 2화 완성 2명·3화 실측 없음)
- 기업 파일럿(스네 11/4 미팅, 돈 없는 2~4주 파일럿 제안)
