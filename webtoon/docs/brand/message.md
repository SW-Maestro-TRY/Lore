# 무엇이라고 말하는가

한 문장으로 모든 걸 설명하려 하지 않고, 층마다 역할을 나눕니다. 정의와 두 경험은 [README.md](README.md).

## 층별 문장

| 층 | 문장 | 쓰는 곳 |
| --- | --- | --- |
| 서비스 정의 | LORE 는 내 캐릭터와 세계관, 곧 개인 IP 가 이야기 속에서 살아 움직이게 하는 AI 창작 플랫폼입니다. 지금은 만화로 보여 줍니다. | 서비스 정의, 첫 설명. [README.md](README.md) 1절과 같은 문장 |
| 한 문장 | 내가 만든 캐릭터와 세계가, 상상 속에서 현실의 콘텐츠로. | 표지, SNS 프로필 |

| 핵심 가치 | 내 개인 IP 가 사건 속에서 살아 움직인다. 체험은 「진짜 내 캐릭터라면 이럴 것 같아!」, 만들기는 「내가 상상한 세계가 실제로 구현됐어!」 | 기획서 요약, 발표, 품질을 말하는 자리 |
| 핵심 능력 | 미리 설계한 세계·사건·인물 관계 + 캐릭터 이해 + 설득력 있는 상호작용. 캐릭터 설명에 적힌 대로 움직이고, 없는 성격을 지어 넣지 않습니다. | 기술 설명, AI 파이프라인을 말하는 자리 |
| 기반 | 캐릭터는 지키고 이야기는 채웁니다. | 프롬프트·검수 기준, 품질을 묻는 자리 |
| 웹툰 제품 정의 | LORE 웹툰은 내 캐릭터가 사건 속에서 살아 움직이는 모습을 만화로 만드는 AI 웹툰 스튜디오입니다. 사건을 LORE 가 준비하면 세계관 체험, 사용자가 준비하면 웹툰 만들기입니다. | 웹툰 소개, 랜딩 |
| 두 경험 | 기준은 사건을 누가 준비하나. **세계관 체험** — LORE 의 사건에 내 캐릭터를 퐁당. **웹툰 만들기** — 내 사건·내 세계를 작품으로. 둘이 함께 쓰는 도구는 **세계관 만들기**. 「캐릭터만 있으면 우리 사건으로, 세계관까지 있으면 네 사건으로」 | 제품 구조, 기능 설명 |
| 구조 | 체험: 세계관 고르기 → 사건 고르기 → 내 캐릭터 넣기 → 만화 → 다른 사건 · 다른 세계. 만들기: 캐릭터 · 이야기(· 내 세계관) → 이야기 구성 → 웹툰 · 편집 → 다음 화 | 흐름 설명 |
| 차별점 | 그림 한 장도, 캐릭터와의 대화도, 「어떤 웹툰을 만들까」도 아닙니다. 「얘가 이 사람을 만나면 어떻게 될까?」라는 호기심으로 시작해, 캐릭터가 사건 속에서 어떻게 구는지를 봅니다. | 포지셔닝 |
| 메인 타깃 말 | 이 사건에 내 자캐가 들어가면? 얘라면 어떻게 하는지 만화로 보여 드려요. | 랜딩 약속, 메인 타깃 대상 문구 |
| 광고 | "만약 내 ○○가 ○○에 떨어진다면?" → 실제로 만들어 본 만화를 보여 준다 | 유입 광고 |
| 기업 협업 | 캐릭터 AI 나 세계관 서비스의 등장인물·사건 속에, 사용자가 자기 캐릭터를 넣어 만화로 만들고 공유하는 창작 경험으로 잇습니다. | 기업 협업 제안 |

세 층을 섞지 않습니다. 팔 것은 핵심 가치(살아 움직인다)이고, 잘해야 하는 것은 핵심 능력(사건과 상호작용)이고,
설정 보존·캐붕 방지·세계관 일관성은 그 둘을 떠받치는 기반입니다. 「설정 보존율 95%」를 파는 서비스처럼 말하지
않습니다. 훅은 「보고 싶다」를 만드는 문장이고, 기준은 「믿을 수 있다」를 만드는 문장입니다. 광고·랜딩 상단에는
훅만, 품질을 묻는 자리에는 기준을 씁니다.

## 랜딩·기획서의 약속

약속은 경험마다 둡니다. 세계관 체험 약속이 앞, 웹툰 만들기 약속이 다음입니다.

| 경험 | 약속 | 한 줄 |
| --- | --- | --- |
| 세계관 체험 | 이 사건에 내 캐릭터가 들어가면 | 세계·등장인물·사건은 준비돼 있어요. 캐릭터만 넣으면 그 성격대로 사건 속에서 움직입니다. |
| 세계관 체험 | 적은 대로, 캐붕 없이 | 적힌 성격은 뒤집지 않고 없는 성격은 붙이지 않아요. |
| 세계관 체험 | 다른 사건에 또 넣기 | 한 장면으로 끝나지 않아요. 같은 캐릭터를 다른 사건·다른 세계에 다시 넣을 수 있어요. |
| 웹툰 만들기 | 머릿속 이야기를, 장면으로 먼저 | 이야기를 적으면 AI 가 장면과 대사로 나눠 보여 줘요. 직접 고쳐 본 뒤 웹툰으로 만들 수 있어요. |
| 웹툰 만들기 | 같은 얼굴, 마지막 컷까지 | 설정만 있던 캐릭터가 이야기 속에서 말하고 움직여요. 캐릭터를 넣으면 그 캐릭터가 주인공인 웹툰이 나옵니다. |
| 웹툰 만들기 | 마음에 드는 장면만 남기기 | 아쉬운 장면이 있다면 그 장면만 다시 그려요. 처음부터 전부 다시 만들 필요 없어요. |

랜딩 상단에는 체험 약속을, 웹툰 만들기 약속은 그 아래에 둡니다.

우리가 중요하게 여기는 것 네 가지: 내 캐릭터 그대로 · 내가 고른다 · 쌓인다 · 내 것(올린 사진은 캐릭터를 만드는
데만 쓰고 AI 학습에 쓰지 않음).

## 웹툰의 역할

웹툰은 사용자의 상상과 창작물을 시각적인 이야기로 보여 주는 매체입니다. 체험에서는 캐릭터의 새 모습을 보여 주는
수단이고, 연재에서는 창작자의 서사를 완성된 작품으로 구현하는 수단입니다. 연재는 필수 과정이 아니라 원할 때 고르는
확장이고, 상업 연재작의 완성도나 정기 연재 보장으로 말하지 않습니다. 짧은 만화를 이어 붙여 웹툰을 만들지 않고,
거기서 생긴 사건·관계·선택을 재료로 저장해 웹툰을 새로 짭니다.

- 유입 타깃이 기대하는 것은 "진짜 우리 강아지가 로판 여주가 됐네"라는 순간입니다.
- 메인 타깃은 한 단계 더 나아가 "내가 만든 캐릭터가 진짜 이렇게 행동하네"를 경험합니다.

핵심 경험을 보여 주는 자리(소개서의 「그 순간」 장, 광고)에서는 그림의 완성도보다 내 캐릭터가 이야기 속에서
무엇을 했는지를 먼저 보여 줍니다.

| | 전달할 것 | 예 |

| 제품 · 브랜드 | 내 캐릭터가 살아 움직인다 | 내 캐릭터가 이야기 속에서 살아 움직이는 순간. |

광고는 만들기(창작)를 밉니다. 다음 화 낚시, 읽기 유도는 하지 않습니다.

## 기능을 사용자 가치로 옮길 때

| 기능 설명 | 사용자에게 하는 말 |
| --- | --- |
| 캐릭터 시트로 일관성을 유지 | 첫 장면의 캐릭터가 마지막 장면까지 같은 캐릭터로 |
| 사람이 아닌 대상을 의인화하지 않음 | 넣은 대상을, 그 모습 그대로 이야기 속으로. 강아지는 강아지로 |
| 적힌 성격을 뒤집지 않고 없는 성격을 붙이지 않음 | 캐붕 없이. 적은 그대로, 비어 있는 곳만 채워서 |
| 준비된 사건에 캐릭터 넣기 | 이 사건에 내 자캐가 들어가면? 얘라면 어떻게 하는지 |
| 내가 적은 설정·이야기로 만들기, 장면 확인에서 고치기 | 내가 넣은 것들로, 나만의 1화를. 그리기 전에 장면을 보고 고칠 수 있어요 |
| 설정집(고정 설정) + 진행 상태 | 인물·세계는 그대로 남고, 앞 화에서 일어난 일이 다음 화의 바탕이 됩니다 |
| 다음 화 | 한 번 뽑고 버리는 게 아니라, 같은 캐릭터로 이어 갑니다 |
| 편집실 장 다시 그리기·되돌리기 | 아쉬운 장만 다시, 처음부터 전부 다시 만들 필요 없이 |

## 기업 협업 메시지

기업에는 LORE 를 "서비스가 있으니 써 달라"고만 소개하지 않습니다. 상대의 캐릭터·대화·이야기 경험과 LORE 의 시각적
창작이 만나는 구체적인 파일럿을 제안합니다. 첫 제안은 상대가 허용하는 캐릭터·세계관으로 짧은 만화를 만들어 보는
작은 실험입니다. API 연동, 화이트라벨, 자동 가져오기, 수익 배분, 효과 수치는 확인 전까지 제공 중인 것처럼 쓰지
않습니다. 「확장해」가 아니라 「잇습니다」로 씁니다. 비용은 성과제 + 수수료가 원칙이고 선금은 기본으로 하지 않습니다.
AI 산출물은 저작권이 인정되지 않을 수 있으므로 「IP 를 키우는 재료이자 시험대」까지만 말합니다.

## 소개서를 쓸 때

- 순서는 무엇(정의·핵심 경험) → 왜(문제) → 누구(타깃) → 어떻게(두 경험과 흐름) → 결과물 순입니다. 기능 설명부터 시작하지 않습니다.
- 캐릭터 만드는 시간·한 편 시간·한 편 분량 같은 실제 정보는 앞쪽에 남깁니다. 숫자는 [features-now.md](features-now.md)의 실측값을 날짜와 함께 씁니다.
- 그림체 목록, 비용과 원가, 경쟁 비교, 긴 FAQ, 정부지원 설명은 뒤로 보냅니다. 원가는 대외 자료에 넣지 않습니다.
- 실제 작품은 입력 글 → 실제 장면을 나란히 보여 줍니다. 한 작품으로 처음부터 끝까지 갑니다.
- 최근에 붙은 기능(찜, 검색, 휴지통, 알림 메일, 번역 등)은 넣어도 되지만 앞쪽에 두거나 따로 장을 만들지 않습니다.

## 피할 표현

- "AI 웹툰 생성기"만으로 소개하기. 그림을 만들어 준다는 말만으로는 구분되지 않습니다.
- 「캐릭터 챗봇」「캐릭터와 대화」로 들리게 쓰기.
- 「짧은 만화 → 1화 2화 3화 연재」를 기본 흐름처럼 쓰기. 연재는 원할 때 고르는 확장입니다.
- 「아래는 전부 실제 화면입니다」 같은 설명문·날짜·억지 다리말을 랜딩에 넣기. 화면이 말하게 합니다.
- 「공개 준비 중」「개발 중」 — 다음 화·설정집·댓글·구독은 운영에 있습니다. 캐릭터 키우기의 「베타」 표기는 유지합니다.
- 「매일 20크레딧」 — 무료 지급은 7일 출석 이벤트입니다.
- 격언투 나레이션, 자기 설명 대사, 「마음속 갈림길」로 끝나는 이야기. 선택은 행동으로.
- 발표·소개 자료에 부진한 숫자·놓친 것을 넣기. 잘된 것만.
