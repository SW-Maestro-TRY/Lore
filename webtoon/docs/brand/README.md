# LORE 웹툰 — 서비스를 뭐라고 소개하나

소개서·랜딩·광고·온보딩 문구를 쓰거나 고칠 때 먼저 읽습니다. 2026-09-27 정리.

## 한눈에

| | |
| --- | --- |
| 무엇 | LORE는 웹툰을 만드는 서비스입니다(AI 웹툰 스튜디오). |
| 가치 | 웹툰으로, 사용자의 창작물을 시각적인 이야기로 바꿔 줍니다. |
| 핵심 경험 | 내 캐릭터가 이야기 속에서 살아 움직이는 순간. |
| 메인 타겟 | 자신이 만든 캐릭터와 설정이 있고, 그 캐릭터가 이야기 속에서 살아 움직이는 모습을 보고 싶은 창작자 |
| 유입 타겟 | 좋아하는 대상이나 사진을 새로운 세계관과 이야기에 넣어, 예상하지 못한 웹툰으로 만나 보고 싶은 사용자 |

웹툰은 완벽한 연재작이 목표가 아닙니다. 사용자의 상상과 창작물이 실제 장면이 되는
순간을 보여 주는 매체입니다.
