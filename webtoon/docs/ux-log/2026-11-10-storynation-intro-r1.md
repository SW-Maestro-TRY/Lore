# 스토리네이션 인트로 진입 화면 — 2026-11-10

## 범위

- 세계관 둘러보기 순서: 좀비 아포칼립스(넓은 첫 카드) → 아르카나 마법학교(첫 줄 옆) → 이세계 학교 → BARDO Express → 방공호 : 068 → 에델리아 제국 → 아스테리아 대륙 → 게이트 브레이커.
- 홈의 ‘내 캐릭터를 넣어 볼 세계’는 이세계 학교 → BARDO Express → 방공호 : 068 → 에델리아 제국 → 좀비 아포칼립스 다섯 장을 이 순서로 노출.
- 방공호 표지 이미지의 카드 내 세로 위치를 중앙으로 조정.
- 인트로 전달본의 각 장 사이에 편집실 ‘한 박자’ 여백(지면 폭의 7%)을 적용. 편집실과 같은 기본 비율을 공유하고 여백 지면은 흰색으로 표시.
- 스토리네이션 3개 세계관의 카드에서 전달본 인트로 웹툰으로 진입. 사건 목록에서는 EP 00을 숨기고 제목 오른쪽에 인트로 다시 보기 버튼 추가.
- 인트로 상단의 흐릿한 ‘사건 고르기’ 링크를 ‘건너뛰기’ 버튼으로 변경. 모바일 상단에도 같은 동작 제공.

## 자료와 판단

- 인트로 이미지는 `haeun/스네-세계관-설계-2026-11-08/스네-전달본/img/`의 최종 전달본을 복사해 정적 자산으로 사용. 이세계 학교 8장, BARDO 6장, 방공호 10장.
- 기존 세계관 카드의 구조와 시각 언어를 유지하고, 인트로에는 같은 Play 화면의 탐색 요소를 적용.
- Impeccable 맥락 확인 및 탐지 실행. 탐지의 `transition: width` 2건은 이번 수정과 무관한 기존 `Play.css` 항목.

## 검증

- `npm run build --workspace lore-web` 통과.
- `git diff --check` 통과.
- 로컬 프런트엔드 `localhost:3097`에서 카드 순서와 방공호 이미지 위치 확인.
- 실제 브라우저에서 3개 카드의 인트로 진입, 전체 24장 이미지 응답, 사건 선택, EP 00 숨김, 다시 보기 버튼, 모바일 화면 확인.
- 홈 다섯 세계관의 순서와 노출, 둘러보기의 좀비 넓은 카드·옆 아르카나 카드·다음 줄 세 카드 순서를 데스크톱 화면에서 확인. 모바일에서도 다섯 홈 카드 노출 확인.
- 각 인트로에서 마지막 장을 제외한 장 사이에만 여백이 있고, 실제 높이가 지면 폭의 7%인지 브라우저에서 확인.
- ‘건너뛰기’ 버튼을 데스크톱·모바일에서 눌러 사건 선택 화면으로 이동하는 것을 확인. `tsc --noEmit --incremental false` 통과.
