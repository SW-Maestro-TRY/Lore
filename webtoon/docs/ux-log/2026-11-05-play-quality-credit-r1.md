# 세계관 체험 생성 방식과 비용 안내

- 범위: 사건에 캐릭터를 넣고 웹툰을 만드는 마지막 화면, 일반 웹툰 만들기의 그리기 방식 선택.
- 문제: 체험 화면의 「넣기」 앞에 크레딧과 무료 횟수가 보이지 않았고, 생성 방식도 고를 수 없었다.
- 변경: 파도(기본, Flare)와 너울(GPT Image 2 고화질)을 표시한다. 크레딧 숫자·잔액·무료 횟수·추가 장당 값은 `/nh/allowance` 응답에서 읽고, 읽지 못하면 시작을 막고 재시도 단추를 보인다.
- 기존 작품: 모델 기록이 없는 작품은 GPT Image 2로 이어 그린다. 물결은 새 생성 목록에서만 숨기고 서버 해석은 유지한다.
- 화면 확인: 로컬 Next 앱에 운영 읽기 API를 연결해 Chrome 헤드리스에서 1440px·500px 화면을 캡처했다. 생성 요청은 보내지 않았다. 브라우저 연결 도구는 사용할 수 없었다.
- 미확인: 로그인 계정의 실제 클릭 경로와 새 조합의 한 편 전체 생성 시간. 표시 시간은 전환 전 안내값이므로 실제 운영 생성 후 갱신해야 한다.

## page02 예시 보강

- 「토끼 귀가 떨린 날」 아르카나 마법학교 page02의 기존 GPT Image 2와 Flare 결과를 파도·너울 선택 카드에 나란히 넣었다. 원본은 모두 1024×1536이며 잘라내지 않고 2:3으로 표시한다.
- 원본 시트 프롬프트에서 그림체가 로맨스 판타지임을 확인해 두 카드에 표시했다. 첫 화면 확인 뒤 이미지 최대 너비를 웹툰 만들기 250px, 체험 210px로 줄였다.
- 로컬 Chrome에서 웹툰 만들기·체험 화면을 1440px과 500px 폭으로 확인했다. 결과 캡처는 원본 저장소 `haeun/image2-flare-compare-2026-11-05/ui-*-page02-small.png`에 있다.

## 세계관 사건 오픈 할인

- 로그인 사용자의 사건 생성은 파도 20→15, 너울 30→20크레딧으로 할인한다. 파도에는 「세일」, 너울에는 「파격 세일」 마크를 붙이고 기존 값에 취소선을 그어 실제 차감액과 함께 보여 준다. 게스트의 오늘 무료 생성은 그대로다.
- `/play/allowance`가 사건 전용 금액을 전달하고 `/play/runs`가 같은 금액을 차감한다. `/nh/create`에 `play=true`를 직접 보내도 일반 웹툰 값이 차감되도록 경로를 분리했다.
- 추가 장면의 장당 값은 기존 기준을 유지한다. 할인 종료 날짜는 정하지 않았다.
- 서버 단위 테스트와 웹 빌드가 통과했다. 로컬 Next 앱에서 할인 응답을 주입해 1440px·500px 화면을 확인했고, 가로 넘침은 없었다. 실제 운영 API 응답·결제는 아직 확인하지 않았다.
- 2026-11-05 재검토: 운영 사건 23건 중 8건은 사용량 기록이 없어 원가 평균에서 제외했다. 기록된 파도 15건은 평균 965원(이미지 호출 589원), p90 1,186원이다. 새 Flare 조합의 운영 완료 사건 원가는 아직 없다. 운영 상품표는 70C/18,900원이나 결제 `ready=false`라 실제 유료 매출로 검증된 가격은 아니다.
- 가격 비교에서 지표를 구별한다. 토끼 귀 page02의 이미지 호출비는 $0.095766→$0.079071(17.4% 감소), 최초 5장은 $0.408773→$0.363067(11.2% 감소)다. 출력 이미지 토큰 6,860→1,715(75% 감소)를 호출비 감소율로 말하지 않는다. 2026-11-06 사용자 결정은 파도 15C·너울 20C다.
- 2026-11-06 화면 재확인: 로컬 Next 앱에 할인 응답을 넣어 데스크톱 1440px·모바일 500px에서 「세일」「파격 세일」 마크, 취소선 가격, 실제 차감액을 확인했다. 모바일 가로 넘침은 없었다. 캡처는 원본 저장소 `haeun/image2-flare-compare-2026-11-05/ui-play-sale-*.png`에 있다.
