# 세계관 체험 생성 방식과 비용 안내

- 범위: 사건에 캐릭터를 넣고 웹툰을 만드는 마지막 화면, 일반 웹툰 만들기의 그리기 방식 선택.
- 문제: 체험 화면의 「넣기」 앞에 크레딧과 무료 횟수가 보이지 않았고, 생성 방식도 고를 수 없었다.
- 변경: 파도(기본, Flare)와 너울(GPT Image 2 고화질)을 표시한다. 크레딧 숫자·잔액·무료 횟수·추가 장당 값은 `/nh/allowance` 응답에서 읽고, 읽지 못하면 시작을 막고 재시도 단추를 보인다.
- 기존 작품: 모델 기록이 없는 작품은 GPT Image 2로 이어 그린다. 물결은 새 생성 목록에서만 숨기고 서버 해석은 유지한다.
- 화면 확인: 로컬 Next 앱에 운영 읽기 API를 연결해 Chrome 헤드리스에서 1440px·500px 화면을 캡처했다. 생성 요청은 보내지 않았다. 브라우저 연결 도구는 사용할 수 없었다.
- 미확인: 로그인 계정의 실제 클릭 경로와 새 조합의 한 편 전체 생성 시간. 표시 시간은 전환 전 안내값이므로 실제 운영 생성 후 갱신해야 한다.

## page02 예시 보강

- 「토끼 귀가 떨린 날」 아르카나 마법학교 page02의 기존 GPT Image 2와 Flare 결과를 파도·너울 선택 카드에 나란히 넣었다. 원본은 모두 1024×1536이며 잘라내지 않고 2:3으로 표시한다.
- 원본 시트 프롬프트에서 그림체가 로맨스 판타지임을 확인해 두 카드에 표시했다. 첫 화면 확인 뒤 이미지 최대 너비를 웹툰 만들기 250px, 체험 210px로 줄였다.
- 로컬 Chrome에서 웹툰 만들기·체험 화면을 1440px과 500px 폭으로 확인했다. 결과 캡처는 원본 저장소 `haeun/image2-flare-compare-2026-11-05/ui-*-page02-small.png`에 있다.

## 웹툰 만들기·세계관 사건 오픈 세일

- 웹툰 만들기와 로그인 사용자의 사건 생성은 모두 파도 20→15, 너울 30→20크레딧으로 할인한다. 파도에는 「세일」, 너울에는 「파격 세일」 마크를 이미지에 스티커처럼 붙이고 기존 값에 취소선을 그어 실제 차감액과 함께 보여 준다. 게스트의 오늘 무료 생성은 그대로다.
- `/nh/allowance`와 `/play/allowance`가 같은 할인 금액과 할인 전 가격을 전달한다. `/nh/create`와 `/play/runs`도 같은 금액을 차감한다. 본문의 `play=true`만으로 별도 할인받는 경로는 만들지 않는다.
- 추가 장면의 장당 값은 기존 기준을 유지한다. 처음에는 할인 종료 날짜를 정하지 않았고, 2026-11-06에 종료일을 11월 15일로 정했다.
- 서버 단위 테스트와 웹 빌드가 통과했다. 로컬 Next 앱에서 할인 응답을 주입해 1440px·500px 화면을 확인했고, 가로 넘침은 없었다. 실제 운영 API 응답·결제는 아직 확인하지 않았다.
- 2026-11-05 재검토: 운영 사건 23건 중 8건은 사용량 기록이 없어 원가 평균에서 제외했다. 기록된 파도 15건은 평균 965원(이미지 호출 589원), p90 1,186원이다. 새 Flare 조합의 운영 완료 사건 원가는 아직 없다. 운영 상품표는 70C/18,900원이나 결제 `ready=false`라 실제 유료 매출로 검증된 가격은 아니다.
- 가격 비교에서 지표를 구별한다. 토끼 귀 page02의 이미지 호출비는 $0.095766→$0.079071(17.4% 감소), 최초 5장은 $0.408773→$0.363067(11.2% 감소)다. 출력 이미지 토큰 6,860→1,715(75% 감소)를 호출비 감소율로 말하지 않는다. 2026-11-06 사용자 결정은 파도 15C·너울 20C다.
- 2026-11-06 화면 재확인: 로컬 Next 앱에 할인 응답을 넣어 데스크톱 1440px·모바일 500px에서 「세일」「파격 세일」 마크, 취소선 가격, 실제 차감액을 확인했다. 모바일 가로 넘침은 없었다. 캡처는 원본 저장소 `haeun/image2-flare-compare-2026-11-05/ui-play-sale-*.png`에 있다.
- 같은 날 웹툰 만들기 `?view=create&step=2`에도 세일 가격을 적용하고 스티커형 라벨을 이미지 모서리에 붙였다. 로컬 읽기 전용 미리보기 API에서 두 품질 가격과 원가를 전달해 전체 페이지를 1440px·500px로 캡처했다. 두 원본 예시 이미지 모두 1024×1536으로 로드됐고 가로 넘침이 없었다. 캡처는 `haeun/image2-flare-compare-2026-11-05/ui-create-sticker-*.png`에 있다. 미리보기 응답은 운영 적용 확인이 아니다.
- 모바일 피드백 반영: 이미지 표시 폭을 최대 250→220px로 줄였고 스티커는 크기를 유지한 채 위로 7px, 오른쪽으로 10px 옮겼다. `ui-create-sticker-mobile-small.png`에서 전체 페이지와 가로 넘침 없음을 다시 확인했다.
- 추가 피드백: 스티커 외곽을 원형 테두리로 바꾸고 더 위·오른쪽으로 뺐다. 안내 문장과 앞 카드 내용에 겹치지 않도록 카드 위 여백과 모바일 카드 사이 간격을 조정했다. 데스크톱·모바일 전체 화면은 `ui-create-round-sticker-*.png`이며 둘 다 가로 넘침이 없다.
- 최신 피드백: 첨부 예시처럼 빨간 뾰족 별모양과 흰 `SALE` 글자로 스티커를 단순화했다. 할인 전·후 크레딧은 카드의 가격 행에서 표시한다. 모바일 `WizardFinal.css`의 한 열 강제 규칙을 두 열로 고쳐 예시 두 개를 나란히 보이고, 두 방식의 소요 시간 안내를 11px로 줄였다. 세계관 체험 카드도 같은 스티커와 모바일 시간 글자 크기를 적용했다. 웹 빌드가 통과했고 로컬 390px·500px·1440px 화면에서 두 품질 선택과 가로 넘침 없음을 확인했다. 캡처는 원본 저장소 `haeun/image2-flare-compare-2026-11-05/ui-create-sale-starburst-*.png`에 있다.
- 후속 수정: 첫 별모양 윤곽과 세일 문구·금액을 복원하고, 파도는 노랑·너울은 빨강으로 바꿨다. 별모양을 키워 오른쪽으로 45도 돌리고 이미지 오른쪽 위로 옮겼다. 모바일 소요 시간 11px과 두 열 배치는 유지했다. 로컬 390px·500px·1440px 캡처는 `haeun/image2-flare-compare-2026-11-05/ui-create-sale-original-star-*.png`에 있고 가로 넘침은 없었다.
- 최종 각도 조정: 두 생성 화면의 세일 스티커 기울기를 20도로 낮추고 안쪽 원형 점선의 지름을 줄였다. 웹툰 만들기 390px 화면 캡처 `ui-create-sale-original-star-20deg-mobile-390.png`에서 두 스티커와 가로 넘침 없음을 확인했다.
- 위치 재조정: 스티커 중심이 이미지 오른쪽 위 모서리에 오도록 올리고 오른쪽으로 빼서 이미지 밖으로 확실히 튀어나오게 했다. 안내 문구와 겹치지 않도록 카드 위 여백을 늘렸다. 390px에서는 오른쪽 스티커만 화면 경계 안쪽으로 7px 보정했고, 최종 전체 캡처 `ui-create-sale-popout-20deg-mobile-390-final.png`에서 가로 넘침 없음을 확인했다.
- 후속 피드백: 두 화면의 세일 스티커 가운데 원형 점선을 제거했다. 별모양·색·가격·20도 회전·위치는 유지한다.
- 최종 선택: 비교 시안 L 「매달린 깃발」을 두 생성 화면에 적용했다. 깃발에는 「오픈 세일중」과 다음 줄 「11.06 ~ 11.15」를 넣고, 할인 가격은 기존 카드 가격 행에 남겼다. 한국 시간 2026-11-06 00:00~11-15 23:59에만 파도 15C·너울 20C를 차감하고, 11-16 00:00부터 20C·30C로 돌아간다. 열린 화면도 종료 시각에 allowance를 다시 읽는다. 경계 단위 테스트와 로컬 390px·500px 두 화면에서 깃발·가격·가로 넘침 없음을 확인했다. 할인 종료 뒤 응답을 모의 주입하면 깃발과 취소선이 사라지고 20C·30C만 보인다. 캡처는 원본 저장소 `haeun/image2-flare-compare-2026-11-05/ui-*-opening-sale-flag-*.png`에 있다.
- 글씨·위치 피드백: 모바일 깃발 문구 11→15px, 날짜 10→13px로 키웠다. 스티커를 이미지 래퍼 대신 카드에 붙여 오른쪽 위로 튀어나오게 했다. 웹툰 만들기·세계관 사건 모두 390px·500px 화면에서 가로 넘침 없음을 확인했고, 최종 캡처는 `ui-*-opening-sale-flag-large-popout-*.png`다.
- 할인 표시 단순화: 깃발과 모든 스티커를 제거하고 할인 전·후 크레딧 바로 아래에 `11.06 ~ 11.15 오픈 세일중`을 작게 표시한다. 웹툰 만들기의 긴 8장·추가 장면 설명, 세계관 사건의 보유 크레딧·기본/추가 장면 안내와 무료 잔여 안내는 선택 화면에서 뺐다. 파도 한 문장·너울 두 문장의 방식 설명은 이전 버전과 동일하다. 390px·500px 두 화면에서 문구와 가로 넘침 없음을 확인했으며 캡처는 `ui-*-sale-inline-*.png`다.
