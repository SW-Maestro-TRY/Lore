# 비회원 무료 진입과 완독 후 가입 안내 · 2026-11-06

- 비회원 입구 카드는 첫 렌더에 `무료`를 보이고, 서버 허용량을 받은 뒤 무료 몫이 0이거나 전체 생성이 막힌 상태라면 뺀다. 조회 실패에도 배지를 뺀다.
- 만들기 화면의 파도·너울은 비회원 무료 몫이 남았을 때 크레딧 가격과 세일 문구 대신 `무료`를 보인다. 로그인 사용자의 실제 크레딧 가격은 서버 응답을 그대로 쓴다.
- UTM 광고 링크로 공개 작품에 들어온 비회원은 서버 응답 전에도 `무료`와 `무료로 웹툰 만들기`를 본다. 무료 몫이 없으면 응답 후 그 문구를 뺀다.
- 본인 작품의 마지막 페이지를 끝까지 읽은 비회원에게만 가입 안내를 띄운다. 작품별로 한 번만 노출하며 닫기, 나중에, 가입/로그인 동작이 있다. 가입 버튼은 가입 탭을 연다. 공개 작품 감상자는 제외한다.
- 신규 가입 보상은 `CreditService` 기본값 20크레딧, 비회원 무료 생성은 `GuestGate` 기본값 하루 2편을 확인했다. 배포 환경에서 이 값을 재정의하면 문구도 맞춰야 한다.
- 사용성 점검: 변경 전 7/10(무료 생성인데 가격 우선 노출, 설문과 가입 안내 동시 노출 가능). 변경 후 9/10(행동·닫기 명확, 모바일에서 읽힘, 공개 작품 제외). 비회원 설문은 가입 안내와 겹치지 않도록 다음 방문 완독 때로 미룬다.
- 로컬 390×844 브라우저에서 입구 무료 배지, 두 품질 카드 무료, 완독 팝업, 가입 탭, 새로고침 후 중복 방지, 공개 작품 제외, UTM 광고 문구를 확인했다. 1440×900 브라우저에서 무료 몫 0인 응답을 주입해 무료 배지가 사라지고 실제 가격으로 돌아가는 것도 확인했다. 생성 모델 호출 없이 기존 완료 작품을 사용했다.
- 2026-11-06 수정: 가입 안내는 비회원이 오늘 무료 몫을 다 썼을 때만 띄운다(서버 전체 마감 `blocked`는 제외). 무료가 남았는데 「로그인하면 한 편 더」가 뜨던 문제를 고쳤다. 띄우는 자리는 ① 내 작품 완독(작품마다 한 번) ② 무료 몫이 없는 비회원이 「다음 편 만들기」·「웹툰 만들기」를 누를 때. 창은 제목 「오늘 무료 횟수를 다 썼어요」, 20크레딧 원형 표시와 「회원가입하면 20크레딧 / 가입하고 바로 한 편 더 만들 수 있어요」, 나중에·회원가입·로그인 단추로 정리했다. 로컬 크롬에서 허용량 응답을 free_left 0/1 로 바꿔 넣어 0일 때만 뜨고 1일 때 안 뜨는 것, 「다음 편 만들기」 누르면 다시 뜨는 것을 확인했다.
