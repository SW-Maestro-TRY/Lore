# 생성 중 홈 화면 추가 안내 · 2026-11-06

## 맥락과 결정

- 일반 웹툰과 세계관 체험의 생성 화면에서 5초 뒤 안내를 띄운다. 한 탭 세션에서 한 번만 보여 생성 단계를 반복해도 방해하지 않는다.
- 실제 앱스토어 출시가 없으므로 웹사이트를 홈 화면에 추가한다는 말과 LORE 아이콘을 쓴다. 생성은 안내 중에도 계속된다.
- 설치 가능한 브라우저는 버튼에서 브라우저 설치창을 연다. 그 외에는 iOS Safari 공유 메뉴 또는 브라우저 메뉴의 수동 경로를 안내한다.
- 닫기·나중에·Esc·배경 누르기로 즉시 돌아갈 수 있다. 버튼 높이는 44px 이상이다.
- 노출, 클릭, 브라우저 창 수락, 설치 확인 이벤트, 설치형 창 열기를 각각 기록한다. iOS 수동 추가는 완료를 직접 알 수 없으므로 설치형 창 열기로 별도 관찰한다.

## 로컬 확인

- 모의 생성 주소 `?view=running&job=mock-running`(PC) 및 `?view=play&world=zombie&ep=hidden-family&stage=making&job=mock-play`(모바일)에서 안내와 수동 방법을 확인했다. 두 화면 모두 브라우저 예외 0건.
- 닫은 뒤 새로고침에서 안내 재노출 0건. 모의 `beforeinstallprompt` 이벤트에서 설치 버튼이 `prompt()`를 호출하고 닫힘을 확인했다. 실제 기기 설치 완료 검증은 이 모의 이벤트에 포함되지 않는다.
- `npm run build --workspace lore-web` 통과. 기존 `ProgressMock.css`의 autoprefixer 경고는 남아 있다.
