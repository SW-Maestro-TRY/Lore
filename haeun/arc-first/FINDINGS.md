# 순서 실험 — P2 → W4 → 씬 → W5 (2026-08-29)

지금 순서는 `P2 → 씬 → W4 → W5` 다. 1화가 매번 씬이 쓴 그대로 나오길래,
순서를 `P2 → W4 → 씬 → W5` 로 바꿔서 W4 를 장면보다 앞에 두고 돌려 봤다.
바탕 run 은 `20260828T140618-9e8a8d`, P1·P2 는 그대로 재사용했다 (같은 전제라야
비교가 된다). 호출 4회 · 41,539토큰 · $0.1154.

돌리는 법: `python run_experiment.py --run <run_id> --result-dir out`

## 얻은 것

**W4 는 고쳐졌다.** 장면을 빼고 주니 Arc 가 사건이 아니라 상태로 나왔다.

| | 옛 Arc 1 | 새 Arc 1 |
| --- | --- | --- |
| 형태 | 3문장 줄거리 | 시작 상태 / 조이는 힘 / 끝 상태 |
| 내용 | "공식 기자회견장에서 실명과 얼굴 공개를 단호히 거부함으로써…" | "숨기기만 하면 예전 일상이 유지된다고 믿는다" → "힘만 감추는 것으로는 안 된다는 것을 깨닫는다" |

**그런데 1화는 거의 안 바뀌었다.** 씬 1(기자회견장에서 공개 거부)과 씬 2(복도에서
마스크를 벗다 장서우에게 목격당함)가 두 번 다 똑같이 나왔다.

## 왜 안 바뀌었나 — 1화를 정하는 것은 P1 이다

`p1.json` 의 `trigger_situations` 세 줄이 그대로 1화다.

1. 정체 불명의 마스크 헌터로 **기자회견장**에 섰을 때, 모든 시선이 모여든다.
2. SS급 신분을 증명하라는 요구가 쏟아질 때마다, 실명과 얼굴을 공개하라는 압박이 따른다.
3. 아무도 없는 **복도에서 마스크를 벗었는데, 누군가 그 모습을 목격**한다.

`p1.txt` 에서 이 칸의 정의는 "A와 B의 충돌이 실제로 터지는 상황 3개" — 인물
설계지 1화 각본이 아니다. 그런데 씬은 `character_sheet_json` 으로 p1 **전문**을
받고, W4 도 `character_sheet` 로 같은 전문을 받는다. 구체적인 상황 세 개가 눈앞에
있으면 그게 1화가 된다.

그래서 진짜 사슬은 이랬다:

```
P1.trigger_situations  →  씬(3장면)  →  엔진 카드("1화 컷은 이 장면의 번역이다")
                                      →  W4(그 장면을 Arc 로 요약)  →  W5(받아쓰기)
```

이 실험이 증명한 것은 **W4 를 앞으로 빼도 1화는 안 바뀐다**는 것이다. 원인이
그보다 앞에 있기 때문이다.

## 부수적으로 본 것

- **`not_yet` 울타리가 가장 센 장면을 잘라 먹었다.** Arc 1 의 `not_yet` 에
  "신분이 장서우 이외 인물에게 완전히 노출되는 것"이 들어갔고, 그 결과 옛 3번
  장면(협회 임원이 카메라를 들이대고 유출 경고가 뜨는 순간)이 사라지고 "게이트
  출동 알람에 임무로 복귀한다"로 바뀌었다. 되돌릴 수 없는 일이 약해졌다.
  Arc 의 울타리를 1화에 그대로 적용하면 압력이 아니라 검열이 된다.
- **W5 는 여전히 창작하지 않는다.** 엔진 카드가 "1화의 컷은 이 장면을 컷으로
  옮기는 일이다"라고 못박으므로, 씬이 있는 한 W5 는 받아쓰기다.
- **W5 가 엔진급 질문을 화 끝 질문으로 복사한다.** `questions_opened` 첫 줄이
  엔진 카드의 `engine_question` 문장 그대로였다("얼굴과 이름과 힘이 모두
  드러나는 순간에도 진짜 자신으로 살아갈 수 있을까"). 1화를 막 본 독자의
  질문이 아니다.

- `p1.json` 의 `fate_beats`("1화 오프닝 시퀀스로 쓴다")도 엔진 카드에 그대로
  실린다. 이번에는 한 번에 하나만 바꾸려고 남겨 뒀다.
