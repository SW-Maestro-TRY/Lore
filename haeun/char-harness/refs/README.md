# refs/

레퍼런스 이미지를 여기에 넣으세요. 파일명은 `config.yaml` 의 각 조건 `refs:` 와 맞추면 됩니다.

기본 설정 기준으로 필요한 파일:

| 파일 | 쓰는 조건 | 내용 |
|---|---|---|
| `face_closeup.png` | B | 캐릭터 얼굴 클로즈업 1장 (정면, 표정 중립 권장) |
| `turnaround.png` | C, D | 턴어라운드 시트 (정면/측면/후면이 한 장에 들어간 이미지) |

- PNG / JPG 둘 다 됩니다. 확장자를 바꾸면 `config.yaml` 의 경로도 같이 바꾸세요.
- 조건 D 는 여기 있는 턴어라운드 + **직전 장면의 생성 결과**를 같이 첨부합니다
  (직전 결과는 실행 중 `outputs/D/` 에서 자동으로 가져오므로 미리 넣을 필요 없음).
- 파일이 없으면 실행 전에 중단됩니다. `--dry-run` 은 경고만 하고 계속 진행합니다.
