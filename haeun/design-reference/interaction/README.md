# LOU 인터랙션 스프라이트

원본 시트 3장(`interaction.png` / `interaction2.png` / `interaction3.png`)을
**제스처별 · 프레임별로 잘라 배경을 없앤** 스프라이트로 정리한 폴더입니다.
세 시트는 서로 겹치는 제스처가 많아서, 시트가 아니라 **제스처**를 기준으로 묶고
같은 제스처의 서로 다른 판을 `seq1` · `seq2` 로 나눴습니다.

## 폴더 구조

```
interaction/
├─ _source/          원본 시트 3장 (자르기 전)
├─ _cards/           예전에 잘라 둔 설명 카드 5장 (글씨가 박혀 있어 제품엔 못 씀)
├─ _cut.py           자르는 스크립트 — 원본을 다시 그리면 이것만 다시 돌린다
├─ _contact.png      잘린 결과를 한 장에 모아 본 확인용 대지
├─ _preview.html     브라우저에서 실제로 눌러/끌어 보는 확인용 페이지
├─ manifest.json     프레임 목록 + 각 컷 설명 (코드에서 읽는 용도)
├─ _manifest.js      manifest.json 과 같은 내용 (file:// 로 열리는 _preview.html 용)
│
├─ click/            클릭 (한 번 누르기)
├─ multiclick/       연속 클릭
├─ drag/             드래그
├─ pet/              터치 & 쓰다듬기
├─ longpress/        길게 누르기
├─ shake/            흔들기 (모바일 전용)
└─ idle/             아무것도 안 하기
```

제스처 폴더 안은 전부 같은 모양입니다.

```
drag/
├─ seq1/   01.png 02.png 03.png 04.png 05.png   ← 연속 1판 (순서대로 이어지는 한 흐름)
├─ seq2/   01.png 02.png 03.png                 ← 연속 2판 (다른 그림체의 같은 흐름)
└─ random/ seq1_03.png seq1_05.png ...          ← 순서 없이 한 컷만 띄워도 되는 것들
```

- **`seqN/`** — 한 줄이 통째로 하나의 이야기입니다. `01 → 02 → 03 …` 순서대로
  넘겨야 말이 됩니다. `seq1` 과 `seq2` 는 **같은 제스처의 다른 판**이라
  섞어 쓰지 말고 하나만 골라 쓰세요 (그림체가 다릅니다 — 아래 표 참고).
- **`random/`** — `seqN` 중에서 **한 컷만 뚝 떼어 놔도 말이 되는 컷들의 사본**입니다.
  "누를 때마다 아무 반응이나 하나" 같은 연출에 그냥 이 폴더에서 하나 뽑아 쓰면 됩니다.
  파일 이름 앞에 원본 위치가 붙어 있습니다 (`seq1_03.png` = `seq1/03.png` 와 같은 그림).
  `manifest.json` 의 `sameAs` 에도 같은 정보가 있습니다.
  - 사람 손이 그려진 컷과 "이렇게 하세요" 안내용 컷(점선 등)은 `random/` 에 안 넣었습니다.
    제품에서 손 그림이 같이 뜨면 이상하니까요. `seqN/` 에는 그대로 남아 있습니다.
  - `click/random/` 만 예외로 **다른 제스처에서 골라 온 사본**입니다.
    세 시트 어디에도 "한 번 클릭" 줄이 없어서, 한 컷짜리로 써도 되는 반응 포즈를
    골라 모았습니다.

## 어느 판(seq)을 쓸지

| 제스처 | seq1 | seq2 |
| --- | --- | --- |
| `multiclick` | 5컷 · 시트2 (완성 채색) | 5컷 · 시트3 (러프 스케치) |
| `drag` | 5컷 · 시트2 (완성 채색) | 3컷 · 시트3 (러프 스케치) |
| `pet` | 5컷 · 시트2 (완성 채색) | 6컷 · 시트3 (러프 스케치) |
| `longpress` | 5컷 · 시트2 (완성 채색) | — |
| `shake` | 5컷 · 시트1 | 6컷 · 시트2 (완성 채색) |
| `idle` | 5컷 · 시트1 (깜빡임·하품) | 5컷 · 시트1 (잠들기) |

**제품에 넣을 땐 시트2 판(대부분 `seq1`, `shake` 는 `seq2`)으로 통일하는 걸 권합니다.**
시트3은 선이 러프한 다른 그림체라 같은 화면에 섞이면 튑니다. 시트1과 시트2는
그림체가 거의 같습니다.

## 각 컷이 무슨 장면인지

`manifest.json` 에 컷마다 한 줄 설명이 붙어 있습니다. 예:

```json
"drag": {
  "sequences": {
    "seq1": {
      "source": "sheet2_five_gestures.png",
      "size": [346, 178],
      "frames": [
        { "file": "seq1/01.png", "note": "끌 수 있다는 안내 (점선 + 손)", "hasHand": true },
        { "file": "seq1/02.png", "note": "손에 잡혀 끌려가기 시작",       "hasHand": true },
        { "file": "seq1/03.png", "note": "커서를 따라 헤엄친다",          "hasHand": false },
        ...
```

- `size` — 그 시퀀스의 **모든 컷이 공유하는 판형**입니다. 한 시퀀스 안에서는
  캔버스 크기가 똑같아서 그냥 갈아 끼우면 흔들림 없이 애니메이션이 됩니다.
  시퀀스가 다르면 판형도 다릅니다 (`object-fit: contain` 으로 받으면 편합니다).
- `hasHand` — 사람 손이 그려져 있는 컷. 제품에서는 보통 건너뜁니다.

## 확인해 보기

- `_contact.png` — 잘린 55컷을 체커보드 위에 한 장으로 모은 그림.
- `_preview.html` — 브라우저로 그냥 열면 됩니다(서버 필요 없음).
  루를 클릭 / 연타 / 끌기 / 꾹 누르기 / 쓰다듬기 해 보고, 위쪽에서 `seq1` ↔ `seq2` 를
  바꿔 가며 비교할 수 있습니다.

## 다시 자르려면

원본 시트를 다시 그렸거나 자른 위치가 마음에 안 들면 `_cut.py` 의 `SPEC`
(줄마다 `y0`/`y1` 과 프레임 경계 `xs`) 만 고치고 다시 돌리면 됩니다.
제스처 폴더는 매번 통째로 지웠다 다시 만들기 때문에, **잘린 png 를 손으로 고치면
다음 실행 때 날아갑니다.** 손보정이 필요하면 원본 시트를 고치세요.

```
cd haeun/design-reference/interaction
python _cut.py             # 다 자르고 manifest 까지 다시 만든다
python _cut.py --contact   # 확인용 대지만 다시 만든다
```

배경은 자동으로 따냅니다 — 원본의 부드러운 그라데이션(저주파)을 배경으로 보고,
그 위에 얹힌 선(고주파)만 남긴 뒤 안쪽 구멍을 채우는 방식입니다. 카드 테두리 같은
얇고 긴 선과 아주 작은 얼룩은 버립니다.

## 알려진 한계

- 드래그 안내 컷(`drag/seq1/01.png`)의 **점선 경로는 너무 흐려서 대부분 지워졌습니다.**
  안내가 필요하면 점선은 CSS/SVG 로 따로 그리는 편이 낫습니다.
- `shake/seq1/05.png` · `shake/seq2/05.png` 의 검은 연기, `pet/seq2` 일부 컷 아래쪽에
  원본 카드 바탕이 옅게 남아 있습니다. 눈에 크게 거슬리진 않지만 완벽하진 않습니다.
- 러프 스케치 판(시트3)은 원래 선이 흐려서 완성 채색 판보다 가장자리가 지저분합니다.
