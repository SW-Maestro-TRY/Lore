# 「만들고 싶은 내용이 있어요」 — 화면 흐름과 문구

작성 2026-10-01 (#548). [heavy-user-mode-2026-10-01.md](heavy-user-mode-2026-10-01.md) 의
화면 쪽입니다. 그림 시안은 만들지 않습니다 — 새 화면은 코드부터 만듭니다
(`webtoon/docs/rules/ui-skills.md` 6절). 여기는 흐름과 문구입니다.

## 1. 축은 둘이고, 묻는 순서가 있다

| 축 | 묻는 자리 | 선택지 |
| --- | --- | --- |
| **내용이 있나** | 첫 화면 | 아이디어부터 시작 / 만들고 싶은 내용이 있음 |
| **중간에 확인하나** | 「아이디어부터」 쪽에서만 | 바로 만들기 / 확인하고 만들기 |

「만들고 싶은 내용이 있어요」를 고른 사람에게는 두 번째를 묻지 않습니다. 이미 「내
내용대로」를 고른 것이라, 항상 확인하고 갑니다.

사용자에게 「헤비/라이트」「검수」「고급」을 보여 주지 않습니다. 사용자는 자기 상황(내용이
있나, 확인할 건가)만 고릅니다.

| 안에서 부르는 말 | 화면에 쓰는 말 |
| --- | --- |
| checkpoints=false | 바로 만들기 |
| checkpoints=true | 확인하고 만들기 |
| awaiting_scenes | 장면 확인 |
| resume | 이어서 만들기 |
| own mode | 내 내용으로 시작하기 |

## 2. 전체 흐름

```
                    무엇을 만들고 싶나요?
                            │
          ┌─────────────────┴─────────────────┐
          ↓                                   ↓
  아이디어부터 시작할게요              만들고 싶은 내용이 있어요
          │                                   │
   어떻게 만들까요?                      캐릭터 → 내 내용 입력
     ┌────┴────┐                              ↓
     ↓         ↓                        AI 장면 초안
  바로       확인하고                           ↓
  만들기     만들기                       ⏸ 장면 확인·수정 (무기한)
     │         │                              ↓
     ↓         ↓                           시트 확인
  이야기 4  이야기 4                            ↓
     ↓         ↓                             웹툰
  자동 고름  ⏸ 고르기
     ↓         ↓
  시트       ⏸ 시트 확인
     ↓         ↓
  장면       장면 초안
     ↓         ↓
  웹툰       ⏸ 장면 확인·수정 (무기한)
               ↓
             웹툰
```

지금과 달라지는 것:

- **바로 만들기**: 안 바뀝니다. 지금 「빠르게 결과부터」 그대로입니다.
- **확인하고 만들기**: 지금 「2번 확인하며」에 **장면 확인이 하나 더** 붙고, **5분 자동
  진행이 없어집니다.** 멈춤은 사용자가 「이대로 만들기」를 누를 때까지입니다. 나가면
  마이페이지 「만드는 중」에서 이어서 합니다.
- **만들고 싶은 내용이 있어요**: 새 길입니다. 이야기 후보·고르기가 없고, 적은 내용이 바로
  장면이 됩니다.

세 길 모두 장면 확인 화면은 **같은 화면**입니다. 들어오는 길만 다릅니다.

## 3. 화면별 문구

### 3-1. 첫 화면 (지금 입구 `Entry.tsx` 자리)

```
무엇을 만들고 싶나요?

┌ 아이디어부터 시작할게요 ──────────────┐  ┌ 만들고 싶은 내용이 있어요 ─────────────┐
│ 캐릭터를 바탕으로 AI 가 스토리를        │  │ 내가 생각한 내용을 바탕으로 장면을 만들고 │
│ 만들어드려요.                           │  │ 웹툰으로 완성해요.                       │
│                                        │  │                                        │
│ [ AI 와 함께 만들기 ]                   │  │ [ 내 내용으로 시작하기 ]                 │
└────────────────────────────────────────┘  └────────────────────────────────────────┘
```

「이야기」가 아니라 「내용」입니다. 완성된 시나리오가 있어야 한다는 뜻으로 읽히지 않게
합니다. 「비 오는 날 우산을 건네는 장면」 한 줄도 내용입니다.

지금 입구에 있는 「캐릭터를 만들어보고 싶어요」 카드는 그대로 둡니다(세 번째 카드, 또는
아래 작은 링크). 이 문서가 바꾸는 것은 웹툰 만들기 카드 하나를 둘로 나누는 것입니다.

### 3-2. 「아이디어부터」 → 위자드 방식 단계 (지금 토글 문구만 교체)

```
어떻게 만들까요?

⚡ 바로 만들기
   AI 에게 맡기고 빠르게 완성해요. 중간에 확인하지 않아요.

👀 확인하고 만들기
   AI 가 만든 이야기와 장면을 확인하고, 원하는 부분을 고친 뒤 만들어요.
   나갔다 와도 이어서 할 수 있어요.
```

지금 문구 「빠르게 결과부터 / 2번 확인하며」를 이것으로 바꿉니다. 「2번」은 뺍니다(장면
확인이 생겨 세 번이 됩니다).

### 3-3. 「만들고 싶은 내용이 있어요」 → 위자드

단계는 **캐릭터 → 내 내용 → 그림체** 셋입니다. 방식 단계가 없습니다.

내 내용 단계:

```
어떤 내용을 만들고 싶나요?

┌──────────────────────────────────────────────────────────────┐
│ 예: 비 오는 날 학교에서 우산을 건네는 이야기                      │
│                                                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
짧은 아이디어부터 자세한 시나리오까지 자유롭게 적어 주세요.
대사·장면·연출을 적으면 그대로 반영돼요.

장르  [현대 로맨스 ▾]        (제목은 안 적으면 AI 가 짓습니다)  제목 [        ]
```

- 칸은 크게(열 줄 이상 보이게), 길이 상한은 지금 안전 검사 상한(4,000자)과 맞춥니다.
- 얼마나 자세히 쓰느냐가 곧 통제 수준입니다. 안내 문구가 그것을 말합니다.
- 장르는 세계 재료·그림 분위기에 쓰이므로 받습니다. 제목은 선택입니다.

### 3-4. 장면 확인 (세 길 공통, `awaiting_scenes`)

```
웹툰을 만들기 전에 장면을 확인해 보세요
AI 가 이야기를 웹툰의 장면으로 나눴어요. 원하는 내용이 있다면 자유롭게 고칠 수 있어요.
고치지 않아도 돼요.

                                       [ 이대로 웹툰 만들기 ]   [ 장면 다시 나누기 ]

장면 1 / 7                                                               [ 고치기 ]
┌──────────────────────────────────────────────────────────────┐
│ 비 오는 오후, 학교 정문. 민준이 비를 맞으며 서 있다. 서연이 뒤에서    │
│ 나타나 우산을 씌운다. 민준은 당황하고 서연은 무심한 척한다.          │
│ 서연: "같이 쓰자."                                              │
└──────────────────────────────────────────────────────────────┘

장면 2 / 7                                                               [ 고치기 ]
┌──────────────────────────────────────────────────────────────┐
│ …                                                             │
└──────────────────────────────────────────────────────────────┘

                                       [ 이대로 웹툰 만들기 ]
```

- 맨 위에 「이대로 웹툰 만들기」가 가장 크게 있습니다. 「아이디어부터」로 온 사람은 읽지
  않고 눌러도 됩니다.
- 「고치기」를 누르면 그 카드가 글 칸으로 바뀝니다. 칸은 하나, 자유 글입니다. 컷 수·
  카메라·대사를 따로 묻지 않습니다. 적은 것은 그대로 반영되고, 안 적은 것은 AI 가 정합니다.
- 고치면 바로 저장됩니다(저장 버튼 없음). 상단에 「저장됨 · 방금」.
- 「장면 다시 나누기」는 메모 칸과 함께. 이야기 다시 만들기와 같은 모양입니다.
- 장면 합치기·나누기·순서 바꾸기는 첫 판에 없습니다.
- 「만들고 싶은 내용이 있어요」로 온 사람에게는 위 안내 둘째 줄을 「내가 적은 내용을 AI 가
  장면으로 나눴어요」로 바꿉니다.

### 3-5. 나갔다 돌아올 때

랜딩의 「만들던 웹툰」 알약(이미 있음)과 마이페이지 「만드는 중」 목록:

```
📝 만드는 중
──────────────────────────────
우리들의 여름 · 장면 확인 중              [ 이어서 만들기 ]
──────────────────────────────
```

상태 문구: 「이야기 고르는 중」「캐릭터 확인 중」「장면 확인 중」. 「검수」는 쓰지 않습니다.

### 3-6. 떠 있는 진행 알림(`RunningBubble`)

「장면을 확인해 주세요」 한 줄 추가.

## 4. 바뀌지 않는 것

- 바로 만들기의 흐름·시간·비용.
- 이야기 고르기 화면, 시트 확인 화면, 편집실.
- 크레딧. 장면 확인 자리는 호출이 늘지 않습니다.

## 5. 정해야 할 것

1. 「만들고 싶은 내용이 있어요」에서 **시트 확인**을 둘지. 2절은 둔다고 그렸습니다 — 내
   캐릭터의 얼굴이니 보고 가는 게 맞아 보입니다.
2. 확인하고 만들기(기존 사용자)에서 **5분 자동 진행을 없애는 것**에 동의하시는지. 지금
   이야기 고르기·시트 확인에 걸린 5분도 같이 없어집니다(시간이 아니라 사용자의 행동으로
   진행).
3. 무기한 멈춤과 **7일 뒤 작품 폴더 정리**가 부딪힙니다. 멈춰 있는 작품은 정리에서 빼야
   합니다.
4. 멈춘 작품을 며칠 뒤 찾아오려면 로그인이 필요합니다. 「확인하고 만들기」와 「내 내용으로
   시작하기」를 **로그인한 사람만**으로 둘지.
