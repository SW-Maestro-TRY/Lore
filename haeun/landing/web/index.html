      캐릭터 시트를 확인해 주세요

      이제부터 모든 컷이 이 얼굴을 따라갑니다. 원본과 다르면 여기서 다시 만드세요 — 진행한 뒤에는 뒤 컷 전부가 이 시트를 기준으로 그려집니다.

      틀린 부분 고치기 (이름 · 외형 · 고정 소지품)

      여기서 고친 내용은 "수정 반영해서 다시 만들기"를 눌러야 반영됩니다 — 글자만 고치고 "이대로 진행"을 누르면 지금 보이는 그림 그대로 확정됩니다.

      무엇이 마음에 안 드나요? 고른 것과 적은 말이 다시 만들 때 반영됩니다 — 안 골라도 됩니다

      이야기 구조를 확인해 주세요

      자동으로 다시 쓰는 시도(게이트 재시도)를 다 써서 더 못 고쳤습니다. 이대로 진행하면 지금 이 상태 그대로 다음 단계(캐릭터 시트)로 넘어갑니다 — 다시 만들기를 누르면 같은 캐릭터로 이야기를 처음부터 새로 뽑습니다(새 시도이니 다른 결과가 나올 수 있습니다).

      무엇이 마음에 안 드나요? 고른 것과 적은 말이 다시 쓸 때 반영됩니다 — 안 골라도 됩니다

      작품 규칙 모든 단계(스토리·콘티·그림)가 지킵니다 — 다른 설정과 충돌하면 이 규칙이 이깁니다

      콘티(컷 설계)를 확인해 주세요

      자동으로 다시 쓰는 시도(게이트 재시도)를 다 써서 더 못 고쳤습니다. 이대로 진행하면 지금 이 콘티 그대로 그림 단계로 넘어갑니다 — 다시 만들기를 누르면 콘티를 처음부터 다시 짭니다(새 시도이니 다른 결과가 나올 수 있습니다).

      무엇이 마음에 안 드나요? 고른 것과 적은 말이 다시 짤 때 반영됩니다 — 안 골라도 됩니다

      그림 검수 결과를 확인해 주세요

      다시 그려도 못 고친 것

      여기 있는 장은 그대로 완성본에 들어갑니다. 마음에 안 들면 다음 화면에서 장을 골라 직접 다시 그려 주세요 — 그때는 무엇이 문제인지 적을 수 있어서 검수보다 잘 고칩니다.

        검수가 잡아서 다시 그린 것

        아래 장은 처음 그린 것이 서술과 달라서 검수가 다시 그리게 했고, 지금은 통과한 것입니다. 손대실 것은 없습니다.
