## 적용
- 편집실 제목·작품 정보·장/페이지 정보·장면 설명·다시 그리기 폼·도구 패널 글자를 키웠다.
- 다시 그리기 제목과 비용, 수정 항목, 입력칸 사이의 중복 간격을 줄였다.
- 지난 판 안내 문구를 숨기고 썸네일을 68×90px로 키웠다.
- “여기까지가 1화입니다” 안내와 “완성본으로” 버튼을 편집실에서 숨겼다.
- 둘러보기 카드 제목은 유지하고 하트·찜 수·작품 정보·회차 글자를 키웠으며, 제목과 정보 사이 간격을 줄였다.
- 생성 API와 저장·버전 복구 처리 로직은 유지했다. 다시 그리기 확인창의 실행·닫기 진입점은 아래 후속 요청에 맞춰 변경했다.
- 후속 요청: 장소와 상황 입력칸은 160px, 벌어지는 일 입력칸은 240px로 세로 확장했다. 두 칸의 줄간격은 1.55에서 1.7(16px 글자 기준 27.2px)로 늘렸다. Chrome 실제 7쪽 폼에서 높이·줄간격을 측정하고 `editor-taller-fields.png`로 저장했다.
- 후속 요청: 크레딧·이전 그림 보관 안내를 제거하고 하단을 실제 비용이 표시되는 다시 그리기 실행 버튼으로 바꿨다. 닫기 버튼은 제목 오른쪽 ×로 옮겼다. 폼을 열면 기존 상단 트리거는 숨기며 실행은 하단 버튼에서만 한다. 안전 기준으로 인한 무료 재시도는 무료로 표시한다.

## 확인
- 전용 프런트엔드 `localhost:3110` → 백엔드 `127.0.0.1:8098` → 로컬 DB 사본 `lore_editor_polish_1025`로 연결했다. 백엔드 health는 UP이다.
- Chrome에서 실제 작품 `20261001T191238-4f6203`의 편집실을 열어 7쪽 다시 그리기 폼과 장면 설명을 확인했다. 페이지 이미지 7장 모두 로드됐다.
- Chrome 계산 스타일: 작품 제목 21px, 정보 15px, 장면 항목 16px, 장면 본문 17px, 폼 제목 20px, 입력 본문 16px. 초기 검수에서 제목과 크레딧 안내 사이 간격을 10px로 줄였고, 후속 요청으로 안내 문구를 제거했다.
- 1쪽 지난 판은 안내·버전 글자 없이 실제 사진만 68×90px로 표시된다. 끝 안내와 완성본 버튼은 숨김 상태를 확인했다.
- 둘러보기의 실제 카드(카페 사장에게는 비밀이 많다, 가면을 쓰고 온 옛 약혼자 등)를 확인했다. 제목 15px 유지, 정보 15px, 카드 내부 간격 5px이다.
- 외부 메일·유료 생성 키는 전용 실행 환경에서 제외했고, 공유 그림을 옮기는 시작 작업은 껐다. 실제 작품 파일도 이 워크트리에 복사해 사용한다.
- 에디터의 재그리기·저장·복구 동작은 실행하지 않았다.
- `npm run build --workspace lore-web --ignore-scripts` 통과. 기본 prebuild의 랜딩 에셋 동기화는 처음 권한 오류가 났고, 전용 워크트리에서 dev 서버를 시작할 때에는 동기화가 정상 실행됐다.
- 최종 변경에서 `npm run build --workspace lore-web`도 prebuild 포함 통과했다. 변경 범위 밖 `ProgressMock.css`의 기존 autoprefixer 경고만 남았다.
- `git diff --check` 통과.
- 하단 실행/상단 닫기 버튼 후속 변경은 `npx tsc --noEmit --incremental false` 통과. 자동 브라우저 재검수 중 로그인 세션이 만료됐으며, 이후 사용자가 직접 확인을 완료하고 push·PR을 요청했다. 유료 재그리기 요청은 실행하지 않았다.
