## 적용한 화면
- 홈: 확정 갤러리 overlay, 실제 작품 표지, 로젤 시트와 장면별 얼굴 크롭, 장면/장르 섹션. 기존 사업자·법률·문의 링크 유지.
- 웹툰 만들기: 캐릭터·이야기·장르·설정집 / 그림체·그리기 방식·생성 방식의 2단계. 카드 3개 폭 기준 가로 스크롤, 내 캐릭터가 없으면 예시, 있으면 내 것. 새 캐릭터 만들기와 우상단 연필. 캐릭터 이름/설정 중복 입력 제거.
- 새 캐릭터: 이미지·이름·설정 원본 등록. 상단 우측 AI 캐릭터 뽑기. 이미지 변경과 삭제 확인 UI. 파일 읽기 중 저장 방지, 늦은 파일 읽기 응답 무효화.
- 설정집: 별도 팝업, 검색, 내 설정집 우선, 내용 상세, 물음표 도움, 예시 읽기 전용. 내 설정집은 수정 버튼 이후 편집, 취소 시 키워드/고정 항목까지 복원. 계정 변경과 미저장 편집 보호.
- 진행: 데스크톱 A/모바일 B 구조를 실제 Progress에 적용. 폴링·대기·이야기·인물·시트·장면 승인·그림 생성·검수·오류·취소 유지. 모든 생성 단계에서 원래 입력과 로어북 확인. 본문에 둘러보기/입력 도구, 기존 진행 복귀 기능 유지. 대기 팝업의 기다리기와 둘러보기 행동 분리. 새로 들어왔을 때 실제 진행률부터 표시.
- 둘러보기: 기존 검색, 장르/그림체 필터, 내 작품·찜·회차·공개 기능 유지. 모바일 목록과 데스크톱 카드 정리.
- 독서: 표지, 공유/내려받기, 전체 페이지 확대, 회차 목록, 다음 화/소유자 다음 편 만들기, 댓글·구독. 기존 권한과 실제 회차 응답 사용.
- 편집실: 기본은 장면/대사, 다시 그리기 첫 클릭에 해당 쪽 아래 편집 패널. 같은 버튼 두 번째 클릭에 실행. 비용은 allowance 응답. 기존 버전·복원·편집·공유 유지.

## API
- `POST /api/webtoon/v1/characters/original`: 이미지 1개와 이름/설정을 비공개 READY 캐릭터로 저장. AI 생성/크레딧 차감 없음.
- `PATCH /api/webtoon/v1/characters/{id}/original`: 소유권 확인 후 원본 이미지/설정 교체. 기존 공개 상태 해제. AI로 만들었던 카드의 예전 설정을 생성에 섞지 않음.
- 기존 이름/설정 수정, 삭제 API 재사용. UPLOAD/REPLACED_UPLOAD 소스 추가. 원본은 공개 카드 API로 노출하지 않음.
- 이름 60자, 설정 8000자, PNG/JPEG 6MB, 이미지 40M 픽셀 제한. 원본 저장 파일과 생성용 JPEG 사본 구분. 원본 파일이 없으면 다른 캐릭터로 대체하지 않고 오류.
- `webtoon/be/.../V20261024_2321__webtoon_character_original_source.sql`: source CHECK에 새 값 추가. 처음에 `apps/api` 에 두었던 것을 웹툰 마이그레이션 자리로 옮겼다. 운영 DB에는 실행하지 않음.
- 생성 입력 조회에서 소유자의 lorebook을 포함. 타 계정에는 개인 입력을 반환하지 않음.

## 검증
- 최종 TypeScript 검사 통과.
- API_PROXY 없는 기본 `npm run build --workspace lore-web` 프로덕션 빌드 통과.
- 로컬 화면용 API_PROXY=127.0.0.1:4391 빌드는 별도. 운영 설정에 fixture 주소를 넣지 않음.
- Java 회귀 24개 통과: CharacterOriginalTest 6 / PublicCharacterGenerationTest 6 / JobServiceLorebookTest 7 / JobCancelTest 5. 실패 0, 오류 0.
- 실제 React 브라우저: 모바일/데스크톱 캐릭터 수정·삭제 확인창, 설정집 검색/내용/예시 읽기 전용/내 책 수정 취소, 2단계 그림체·품질, 편집실 같은 버튼 2회, 진행 입력의 로어북, 둘러보기→진행 복귀, 원본 업로드→자동 캐릭터 선택을 검증.
- 긴 본문은 실제 저장된 ‘가면을 쓰고 온 옛 약혼자’ 및 기존 mockScenes의 ‘상견례는 아직 이르지만’. 진행 상태·계정·가격은 로컬 fixture로 구성. 실제 생성 엔진 실행 결과로 주장하지 않음.
- 스크린샷은 screenshots/에 보관. 초기 일부 캡처에는 개발 서버 배지가 보임. 최종 판정은 실제 코드와 마지막 캡처 기준.

## 미실행 / 출시 전 확인
- 실제 로그인 계정·S3 presign/업로드·DB migration·운영 생성·결제·이메일/푸시 전송은 실행하지 않았다.
- 외부 모델을 호출하는 유료 생성과 ‘원본 얼굴 유지’ 결과 품질은 이 작업에서 증명하지 않았다. 원본 이미지와 입력이 전달되도록 구현·회귀 검증한 상태다.
- 모든 API 승인 분기의 운영 성공 응답, 다음 화 실생성, 실제 결제/환불은 운영 전 별도 통합 검증 필요.
- 디자인 시안 전체 링크가 제공되지만 실제 화면 캡처가 없는 상태를 ‘시각 검수 통과’로 간주하지 않는다.
- 다국어의 신규 한국어 문구는 기존 fallback을 따른다. 신규 문구 번역 검수는 남아 있다.

## 이어서 작업하기
1. `source-manifest.json`으로 전달 범위를 확인한다. `source-changes.patch`는 기준 커밋의 텍스트 변경/새 코드이며, `source-files.tar.gz`에는 이미지까지 포함한다.
2. 원본 캐릭터 migration을 포함해 dev/stage 통합 환경에서 실제 업로드→조회→수정→삭제→웹툰 생성 입력을 확인한다.
3. 본문 색·레이아웃을 고칠 때 SiteHeader, 마이페이지 구조, 로어북·권한·생성 상태를 삭제하지 않는다.
4. QA의 4391 서버는 메모리 임시 데이터다. 운영 서버 대용이 아니며 외부 주소에 바인딩하지 않는다.
