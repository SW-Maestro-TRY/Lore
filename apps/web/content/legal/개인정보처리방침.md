# LORE 개인정보처리방침

TRY팀(이하 "회사")은 이용자의 개인정보를 소중히 여기며, 개인정보 보호법 등 관련 법령을 지킵니다. 이 방침은 회사가 어떤 정보를 어떤 목적으로 처리하고, 얼마나 보관하며, 이용자가 어떤 권리를 갖는지를 알리기 위한 것입니다.

**먼저 알려드립니다.**

1. 이 서비스는 생성을 위해 **이용자가 올린 사진 원본을 국외(미국)의 AI 사업자에게 전송**합니다. 자세한 내용은 제6조에 있습니다.
2. **완성한 작품은 기본적으로 공개되어 다른 이용자에게 보입니다.** 올린 사진으로 만들어진 캐릭터와 웹툰이 둘러보기 화면에 노출될 수 있습니다. 자세한 내용은 제5조에 있습니다.
3. **로그인하지 않아도 웹툰을 만들 수 있으며, 이때도 부정 이용을 막기 위해 IP 주소를 해시한 값이 저장됩니다.** 자세한 내용은 제1조 4항에 있습니다.

---

## 제1조 (처리하는 개인정보의 항목)

### 1. 회원 가입 시 (필수)

| 항목 | 설명 |
|---|---|
| 이메일 주소 | 계정 식별, 로그인, 통지 |
| 비밀번호 | **원문을 저장하지 않고 BCrypt 해시로만 저장**합니다. 회사도 원문을 알 수 없습니다 |
| 약관 동의 기록 | 만 14세 이상 확인, 이용약관·개인정보처리방침·마케팅 수신 각각의 동의 여부와 동의 시각, 동의한 판 번호 |

> 회사는 **닉네임·이름·생년월일·성별·전화번호·주소를 받지 않습니다.**

### 2. 서비스 이용 과정에서 이용자가 입력·업로드하는 정보

| 항목 | 설명 |
|---|---|
| **업로드한 사진·그림** | 캐릭터 생성의 재료가 되는 이미지 파일 |
| 캐릭터 이름·설명·키워드 | 이용자가 자유롭게 입력하는 설정 |
| 이야기 소재·요청 메모 | 웹툰 생성 시 입력하는 자유 서술, 다시 만들 때 남기는 요청 |
| 캐릭터 시트·이야기·웹툰 페이지·움짤 | 위 입력으로부터 서비스가 만들어 낸 결과물 |
| 작품 제목, 말풍선·스티커·효과음 등 편집 내용 | 편집실에서 이용자가 얹은 내용 |
| 완성 알림용 이메일 주소 | **로그인하지 않은 이용자**가 완성 알림을 받으려고 직접 입력한 주소 |
| 후기 내용과 이메일 주소 | 이용자가 후기를 남길 때 함께 적은 것 |

> ⚠️ 이용자가 자유 입력란(캐릭터 이름·설명·이야기 소재 등)에 실명·연락처 등 개인정보를 적으면 그 정보도 함께 저장되며, **작품이 공개 상태이면 다른 사람에게 보일 수 있습니다.** 자유 입력란에는 개인을 알아볼 수 있는 정보를 적지 않기를 권장합니다.

### 3. 서비스 이용 과정에서 자동으로 만들어지는 정보

| 항목 | 설명 |
|---|---|
| 생성 처리 기록 | 생성 요청 내용, 단계별 진행·성공·실패, 소요 시간, 대기 순번, 오류 코드, 사용 모델, 화질 설정 |
| 크레딧 기록 | 지급·차감·환불 내역과 사유 |
| 서비스 이용 기록 | 화면 이동, 기능 사용, 접속 일시 |
| 로그인 기록 | 인증 토큰(해시), **브라우저 정보(User-Agent)**, 토큰 발급·폐기 시각 |
| 익명 식별자 | 분석용 쿠키 `lore_anon_id`(로그인 전후 이용 흐름을 잇기 위한 임의의 값) |

### 4. 로그인하지 않은 이용자(게스트)에 대해 처리하는 정보 ★

로그인 없이도 웹툰을 만들 수 있게 하면서 부정 이용과 비용 폭주를 막기 위해, 회사는 다음을 처리합니다.

| 항목 | 설명 |
|---|---|
| **IP 주소를 해시한 값** | 하루 이용 횟수를 세기 위한 것입니다. **IP 주소 원문을 그대로 저장하지 않고**, 회사만 아는 값(salt)을 섞어 되돌릴 수 없게 만든 해시로만 저장합니다 |
| 브라우저 식별값 | 이용자의 브라우저에 저장되는 임의의 값으로, "이 브라우저가 만든 작품"을 찾아 주기 위한 것입니다 |
| 완성 알림용 이메일 주소 | 게스트가 직접 입력한 경우에만 |

> IP 해시는 **누구인지 알아내기 위한 것이 아니라 "같은 곳에서 하루에 몇 번 썼는지"만 세기 위한 것**입니다. 다만 해시값도 개인을 구별하는 데 쓰이므로 이 방침에 적어 알립니다.

### 5. 이용자의 브라우저에 저장되는 것

서버가 아니라 이용자 기기에만 저장되며, 브라우저 설정에서 지울 수 있습니다.

| 이름 | 용도 |
|---|---|
| 인증 쿠키(access·refresh) | 로그인 상태 유지. HttpOnly·Secure 로 설정되어 스크립트가 읽을 수 없습니다 |
| `lore_anon_id` 쿠키 | 이용 흐름 분석용 익명 번호 |
| `lore_uid` | 로그인하지 않고 만든 작품을 다시 찾기 위한 값 |
| `lore_my_runs` | 최근에 만든 작품 목록(빠르게 보여주기 위한 사본) |
| `lore_lang`, 편집실 임시 저장값 | 선택한 언어, 편집 중이던 내용 |
| 만들기 중이던 입력값(세션 저장소) | 새로고침해도 입력이 날아가지 않게 하기 위한 임시 보관. 브라우저를 닫으면 지워집니다 |

### 6. 회사가 수집하지 않는 것

회사는 **이름, 생년월일, 성별, 전화번호, 주소, 결제 정보를 수집하지 않습니다.** 현재 서비스에는 결제 기능이 없습니다. 유료 기능 도입 시 이 방침을 개정하고 별도로 알립니다.

## 제2조 (개인정보의 처리 목적)

회사는 수집한 정보를 다음 목적으로만 사용합니다. 목적이 바뀌면 미리 알리고 동의를 받습니다.

1. **회원 관리** — 가입 의사 확인, 본인 식별, 로그인 유지, 탈퇴 처리, 공지 전달
2. **서비스 제공** — 캐릭터·이야기·웹툰·움짤 생성, 결과물 저장·제공·내려받기, 편집실 기능, 완성 알림 발송
3. **이용 한도와 크레딧 관리** — 크레딧 지급·차감·환불, 게스트 하루 한도 계산, 전체 생성량 제한
4. **부정 이용 방지** — 한도 우회, 자동화 도구를 이용한 대량 요청 차단
5. **콘텐츠 검수** — 부적절한 업로드 차단, 타인 권리 침해 여부 확인, 생성 결과의 품질 확인
6. **서비스 운영·개선** — 오류 원인 분석, 생성 성공률·소요 시간·비용 분석, 화면 개선을 위한 이용 흐름 분석
7. **법령상 의무 이행** — 관련 법령이 요구하는 기록의 보존, 분쟁 대응

> ★ 제6호의 "서비스 개선"은 **생성 성공·실패 여부, 소요 시간, 오류 코드, 사용 모델, 비용 같은 운영 기록**을 보는 것을 말합니다. **이용자가 올린 사진 자체를 AI 학습에 쓰지 않습니다**(이용약관 제8조).

## 제3조 (운영자의 열람과 검수)

1. 회사는 부적절한 콘텐츠를 걸러 내고 생성 품질을 확인하기 위해, **운영자가 업로드된 사진과 생성 결과물을 직접 눈으로 확인**하는 경우가 있습니다.
2. 열람은 **검수와 장애 대응에 필요한 최소한의 범위**에서만 합니다.
3. 검수 결과와 그 사유는 서비스 운영을 위해 기록으로 남습니다.

## 제4조 (개인정보의 보유·이용 기간) ★

| 업로드한 사진, 캐릭터 시트, 생성물 | **이용자가 삭제를 요청할 때까지, 또는 탈퇴 후 `[[탈퇴 후 파기 기간]]` 까지** |

| 게스트 하루 이용 횟수(IP 해시) | `[[게스트 카운터 보존기간 — 예: 90일]]` |

법령에 따라 보존해야 하는 정보가 있는 경우, 그 법령이 정한 기간 동안 해당 정보만 분리하여 보관합니다.

## 제5조 (작품의 공개와 그로 인한 정보 노출) ★

1. **완성한 작품은 기본적으로 공개 상태가 되어, 둘러보기 화면에서 누구나 볼 수 있습니다.**
2. 공개된 작품에서는 다음이 함께 보일 수 있습니다.
   - 생성된 캐릭터 이미지와 웹툰 페이지
   - 작품 제목과 대사·나레이션
   - 이용자가 입력한 캐릭터 이름·설명이 결과물에 반영된 부분
3. **회원**은 마이페이지에서 언제든지 작품을 비공개로 바꿀 수 있습니다. 비공개로 바꾸면 둘러보기에서 내려가고, 이미지 파일도 누구나 접근할 수 있는 경로에서 제한된 경로로 옮겨집니다.
4. **게스트는 공개·비공개를 직접 바꿀 수 없습니다.** 내림을 원하면 lightbluue6@gmail.com 로 요청해 주십시오.
5. 공개된 작품의 이미지 주소를 이미 알고 있는 사람이나, 외부에 저장된 사본까지 회사가 회수할 수는 없습니다.
6. **회사는 작품을 공개할 때 이용자의 이메일 주소를 함께 보여주지 않습니다.**

## 제6조 (개인정보의 국외 이전) ★

**회사는 캐릭터·웹툰·움짤을 만들기 위해, 이용자가 올린 사진과 입력한 설정을 국외의 AI 사업자에게 전송합니다.** 개인정보 보호법 제28조의8에 따라 다음과 같이 알립니다.

| 구분 | 내용 |
|---|---|
| 이전받는 자 | ① `[[OpenAI 정확한 법인명 — 예: OpenAI OpCo, LLC]]`<br>② `[[Google 정확한 법인명 — Gemini API 제공 주체]]`<br>③ `[[Anthropic — 실제 사용 시 기재]]` |
| 이전받는 자의 연락처 | `[[각 사업자의 개인정보 문의처]]` |
| 이전되는 국가 | 미국 |
| 이전 일시 및 방법 | 이용자가 캐릭터 생성·웹툰 생성·컷 다시 그리기를 요청하는 **그 시점에**, 암호화된 통신(HTTPS)으로 해당 사업자의 API에 전송 |
| 이전되는 항목 | 1. 이용자가 올린 **사진 원본**<br>2. 사진에서 만든 **캐릭터 시트 이미지**<br>3. 이용자가 입력한 **캐릭터 이름·설명·키워드·이야기 소재**<br>4. 생성 지시문(프롬프트)과 캐릭터 생김새 설명 텍스트 |
| 이전 목적 | 캐릭터 시트·웹툰 컷·움짤 이미지 생성, 이야기와 대사 텍스트 생성 |
| 이전받는 자의 보유·이용 기간 | `[[각 사업자의 API 데이터 보존기간 — 공식 문서 확인 후 기재. 남용 모니터링 목적의 보관 기간 포함]]` |
| 학습 사용 여부 | 회사는 해당 사업자가 **전송된 데이터를 AI 모델 학습에 사용하지 않는 조건의 API**를 이용합니다 |

**중요 안내**

1. 회사는 **이메일 주소·비밀번호 등 계정 정보를 국외의 AI 사업자에게 전송하지 않습니다.** 전송되는 것은 위 표의 이미지와 텍스트뿐이며, 누구의 것인지 식별할 수 있는 계정 정보는 함께 보내지 않습니다.
2. 이용자는 이 국외 이전을 **거부할 수 있습니다.** 다만 이 전송은 생성이라는 **서비스의 본질적 기능에 필요한 것**이므로, 거부하면 해당 기능을 이용할 수 없습니다. 거부하려면 생성 기능을 이용하지 않거나 탈퇴하면 됩니다.
3. **어느 사업자를 쓰는지는 기능과 설정에 따라 달라집니다.** AI 사업자가 바뀌거나 추가되면 회사는 이 방침을 개정하고 사전에 알립니다.
4. 별도로, 완성 알림 메일 발송을 위해 **Google LLC 의 Gmail 서버(미국)** 를 통해 이용자의 이메일 주소와 작품 제목·링크가 전송됩니다.

## 제7조 (개인정보 처리의 위탁)

회사는 안정적인 서비스 제공을 위해 다음과 같이 업무를 위탁합니다.

| 수탁자 | 위탁 업무 | 보관 위치 |
|---|---|---|
| Amazon Web Services, Inc. | 서버·데이터베이스·이미지 저장소(S3)·배포망(CloudFront) 운영 | `[[AWS 리전 확인 — 서울(ap-northeast-2) 기준으로 작성됨]]` |
| Google LLC | 완성·실패 알림 메일 발송(Gmail SMTP) | 미국 |
| 주식회사 카카오 | 작품 공유하기 기능(공유 링크 전달) | 대한민국 |

- 카카오 공유 기능은 **이용자가 공유 버튼을 눌렀을 때만** 동작하며, 전달되는 것은 작품의 공개 링크와 그 링크가 담고 있는 제목·표지 이미지입니다. 계정 정보는 전달되지 않습니다.
- 회사는 위탁계약 시 개인정보가 안전하게 관리되도록 필요한 사항을 규정하고, 수탁자가 이를 지키는지 감독합니다. 위탁 내용이 바뀌면 이 방침을 통해 알립니다.

   - 종이에 출력된 정보: 분쇄하거나 소각
3. 법령에 따라 보존해야 하는 정보는 그 기간 동안 다른 정보와 분리하여 보관한 뒤 파기합니다.

## 제12조 (개인정보의 안전성 확보 조치)

회사는 다음의 조치를 하고 있습니다.

1. **비밀번호 암호화** — 비밀번호는 원문을 저장하지 않고, 검증된 BCrypt 해시 방식으로만 저장합니다. 회사도 원문을 알 수 없습니다.
2. **IP 주소의 비식별 처리** — 게스트 이용 횟수를 세는 데 쓰는 IP 주소는 원문을 저장하지 않고, 회사만 아는 값을 섞은 해시로만 저장합니다.
3. **전송 구간 암호화** — 이용자와 서버 사이, 서버와 외부 AI 사업자 사이의 통신을 HTTPS로 암호화합니다.
4. **인증 쿠키 보호** — 로그인 쿠키를 HttpOnly·Secure·SameSite 로 설정하여 스크립트가 읽거나 다른 사이트에서 함께 보내지 못하게 합니다. 접속 토큰은 30분마다 다시 발급되며, 로그인 상태는 최대 90일이 지나면 만료됩니다.
5. **비공개 작품의 접근 통제** — 비공개로 둔 작품의 이미지는 누구나 접근할 수 있는 경로에 두지 않고, 한시적으로만 유효한 링크를 통해서만 접근하게 합니다.
6. **분석 기록의 최소화** — 이용 흐름 분석에는 미리 정한 항목만 저장하고, 브라우저 정보는 "모바일/데스크톱" 두 값으로만 줄여 저장하며, 유입 주소의 뒷부분(쿼리)은 떼어 냅니다.
7. **접근 권한 관리** — 개인정보에 접근할 수 있는 사람을 최소한으로 제한합니다.
8. **최소 수집** — 서비스 제공에 꼭 필요한 정보만 수집합니다.

다만 회사는 기술적 조치에도 불구하고 해킹 등 예측하기 어려운 사고가 발생할 수 있음을 알리며, 사고 발생 시 법령에 따라 지체 없이 이용자에게 알리고 신고합니다.

## 제13조 (쿠키 등 자동 수집 장치)

1. 회사는 로그인 상태를 유지하기 위해 쿠키를 사용합니다.
2. 회사는 이용 흐름을 분석하기 위해 익명 번호 쿠키(`lore_anon_id`)를 사용합니다. 이 쿠키는 발급일로부터 **400일** 동안 유지됩니다. 이 번호는 개인을 알아보기 위한 것이 아니라, 같은 이용자의 화면 이동을 이어 보기 위한 임의의 값입니다.
3. **회사는 Google Analytics 등 외부 분석 서비스를 사용하지 않으며, 광고 목적의 추적을 하지 않습니다.** 분석은 회사가 직접 운영하는 서버에서만 합니다.
4. 이용자는 브라우저 설정에서 쿠키 저장을 거부할 수 있습니다. 다만 거부하면 로그인 유지 등 일부 기능을 이용할 수 없습니다.
