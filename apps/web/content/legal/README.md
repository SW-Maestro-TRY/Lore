# 게시용 법적 문서

이 폴더의 `.md` 파일은 `/legal/terms` · `/legal/privacy` 화면이 그대로 읽어
**사용자에게 보여주는 글**입니다.

## 여기를 직접 고치지 마세요

원본은 `webtoon/docs/legal/` 의 작업본입니다. 작업본을 고친 뒤

```
python3 webtoon/docs/legal/게시본-뽑기.py
```

를 돌려서 이 폴더를 다시 만듭니다. 두 벌을 손으로 맞추면 반드시 어긋납니다.

## 왜 두 벌인가

작업본에는 게시하면 안 되는 것이 섞여 있습니다 — "법률 검토 전 초안이라
그대로 게시해서는 안 된다"는 경고, 아직 정하지 못한 정책 메모, 구현이 안 된
항목 목록. 전에는 화면이 작업본을 통째로 읽어서 그 경고문이 사용자에게 그대로
보였습니다. 뽑기 스크립트가 그것들을 떼어 냅니다.

## 아직 안 채운 칸

본문에 `[[사업자명]]` 처럼 남은 칸이 하나라도 있으면 **화면이 문서를 내보내지
않고 "준비 중" 이라고만 말합니다**(`apps/web/app/legal/[doc]/page.tsx`).
사업자명·연락처·보존기간이 빈 약관은 효력을 기대하기 어렵고, 빈칸을 사용자에게
보여주는 것보다 준비 중이 솔직하기 때문입니다.

무엇이 남았는지는 뽑기 스크립트가 찍어 줍니다.
